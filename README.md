# 🏅 PARALYMPICS GAMES DASHBOARD

Welcome to the **Paralympics Games** Dashboard project!

This project showcases an interactive Paralympics Games Dashboard built in Power BI to analyze medal distribution, sports performance, country rankings, and continent-wise participation insights. The dashboard helps users explore Paralympic Games statistics through dynamic and visually engaging reports.

## 🚀 Features

📈 Interactive charts and KPI visuals

🏅 Medal analysis by country and sport

🌍 Continent-wise participation insights

🥇 Gold, Silver, and Bronze medal composition tracking

📊 Sport-wise performance comparison

🗺️ Geographic visualization of participating countries

🎯 Dynamic slicers and drill-down analysis

📂 Clean and structured dataset integration

## 🛠️ Tech Stack

Power BI – Dashboard creation & visualization

Microsoft Excel / CSV – Data source

DAX – Measures & calculations

Power Query – Data cleaning & transformation

## 📈 Dashboard Analysis

🏅 Medal Analysis by Country

The dashboard provides detailed medal insights for participating countries.
Countries like the United States, Germany, and United Kingdom secured the highest number of medals.

🏃 Sport-Wise Performance

Sport-wise medal analysis helps identify the most competitive Paralympic sports.
Athletics and Swimming recorded the highest medal counts.

🥇 Medal Composition Analysis

The dashboard visualizes the distribution of:

Gold Medals

Silver Medals

Bronze Medals

This helps compare overall medal composition across events.

🌍 Geographic Analysis

Interactive map visuals allow users to analyze continent-wise and country-wise participation and performance.

🎯 Dynamic Filtering

Users can filter dashboard insights based on:

Sport Category

Games Continent

Participating Countries
